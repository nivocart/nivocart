# Security Policy

## Supported Versions

Always use the latest release of NivoCart to report vulnerabilities.

| Version | Supported          |
| ------- | ------------------ |
| 2.5.5   | ✅                |
| 2.5.4   | ❌                |
| 2.5.3   | ❌                |
| 2.5.2   | ❌                |
| 2.5.1   | ❌                |
| 2.5.0   | ❌                |
| < 4.0   | ❌                |

## Reporting a Vulnerability

If you find one or more security issues or vulnerabilities in the code,
Please email us at: contact@nivocart.org

Please provide as much detail as possible, so we can assess
the issue being raised.

Thank you.
