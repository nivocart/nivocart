# Security Policy

## Supported Versions

Always use the latest release of NivoCart to report vulnerabilities.

| Version | Supported          |
| ------- | ------------------ |
| 2.5.3   | ✅                |
| 2.5.2   | ❌                |
| 2.5.1   | ❌                |
| 2.5.0   | ❌                |
| < 4.0   | ❌                |

## Reporting a Vulnerability

If you find one or more security issues or vulnerabilities in the code,
Please email us at: contact@nivocart.org

However, the most effective way to report a security risk, would be
to create a new issue at Github, in the nivocart/nivocart repository.

In both cases, please provide as much detail as possible, so we can assess
and reproduce the issue being raised.

Thank you.
